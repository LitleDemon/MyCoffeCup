## 👤 Для пользователя

### Регистрация и вход

**Страница:** `/login.html` (кнопка **«Войти»** в правом верхнем углу)

1. Открой страницу входа.
2. Вверху — две вкладки: **«Вход»** и **«Регистрация»**. Переключаются кликом.
3. **Регистрация:** заполни имя, email и пароль (минимум 6 символов).
4. **Вход:** email и пароль от аккаунта.

После успешного входа:
- В шапке вместо «Войти» появится **твоё имя** — клик ведёт в «Мои заказы».
- Рядом — кнопка **«Выйти»**.
- В навигации появится ссылка **«Мои заказы»**.

**Демо-аккаунты для тестирования:**

| Email | Пароль | Роль |
|---|---|---|
| `user@coffee.ru` | `user123` | обычный пользователь |
| `admin@coffee.ru` | `admin123` | администратор |

### Каталог

**Страница:** `/` (главная)

Главная страница — каталог всех товаров: кофе, чай, десерты.

**Что есть на странице:**
- **Поиск** — поле сверху, ищет по названию в реальном времени.
- **Фильтр по категории** — селект «Кофе / Чай / Десерты / Все».
- **Чекбокс «Только сезонные»** — если отмечен, показывает только сезонные напитки.
- **Сетка карточек** — фото, название, описание, цена, кнопка действия.

**Сезонные товары:**
- Идут **первыми** в каталоге.
- Помечены оранжевым бейджем **«Сезон»** на фото.

**Выбор размера на карточке:**
- У напитков (кофе, чай) под описанием — чипы **S / M / L**.
- Клик по чипу меняет цену на карточке.
- Для десертов размеров нет — фиксированная цена.

**Добавление в корзину:**
1. Выбери размер (для напитков).
2. Нажми **«В корзину»**.
3. Кнопка превращается в счётчик **`[−] N [+]`**.
4. В шапке рядом с 🛒 появляется цифра — общее количество товаров в корзине.

**Изменение количества прямо на карточке:**
- **`+`** — добавить ещё одну единицу.
- **`−`** — убавить (при количестве 1 удаляет позицию и возвращает кнопку «В корзину»).
- **Поле ввода** — можно вписать число вручную и нажать Enter.

### Страница товара

**Открывается:** кликом по фото или названию в каталоге

Здесь можно собрать полноценную конфигурацию напитка.

**Что есть на странице:**

1. **Фото** — крупное, с бейджем «Сезон» для сезонных.
2. **Название и описание.**
3. **Размер** — чипы **S / M / L** с ценами. Клик меняет цену в «Итого».
4. **Добавки** — чекбоксы сиропов и топпингов (только для напитков):
   - У каждого — цена (`+30 ₽`).
   - Сезонные топпинги помечены бейджем **«сезон»**.
   - Отметь нужные.
5. **Итого** — пересчитывается в реальном времени: цена размера + выбранные топпинги.
6. **Кнопка «В корзину»** — превращается в `[−] N [+]` после добавления.

**Важно:** если поменять размер или топпинги после добавления в корзину — это будет **новая позиция**. Первая конфигурация останется в корзине с прежним количеством.

### Корзина

**Страница:** `/cart.html` (иконка 🛒 в шапке)

**Каждая позиция содержит:**
- Фото и название товара.
- **Вариант** — размер и список топпингов (например, «Размер M · Карамельный сироп, Маршмеллоу»).
- **Цена за штуку** — итоговая с учётом размера и топпингов.
- **Счётчик** `[−] N [+]` — изменить количество.
  - Поле ввода работает вручную (Enter или клик вне поля).
  - При убавлении до 0 позиция удаляется.
- **Сумма по строке** — цена × количество.
- Кнопки:
  - **✎** — редактировать конфигурацию.
  - **✕** — удалить позицию.

**Редактирование позиции (кнопка ✎):**
1. Откроется модальное окно.
2. Выбери другой размер (если напиток).
3. Отметь/сними топпинги.
4. Цена «за 1 шт» пересчитывается в реальном времени.
5. **«Сохранить»** — позиция обновится.

**Особенность мерджа:** если после редактирования новая конфигурация совпала с уже существующей позицией в корзине — количества **складываются**, а не появляется дубликат.

**Итоговая панель справа:**
- **Товаров** — общее количество штук.
- **Сумма** — общая стоимость.
- Кнопка **«Оформить заказ»** → переход на страницу оформления.
- **«Продолжить покупки»** → возврат в каталог.

**Если корзина пуста:** показывается сообщение «Ваша корзина пока пуста» и кнопка перехода в каталог.

### Открытка к заказу

**Где:** на странице `/cart.html`, блок **«🎨 Украсить открытку к заказу»** (раскрывающийся)

Декоративная функция — можно приложить к заказу персональную открытку с эмодзи и текстом.

**Как пользоваться:**

1. **Раскрой** блок «Украсить открытку».
2. **Перетащи эмодзи** из палитры (☕ 🥐 🍰 🌸 ❤️ ⭐ 🎉 …) на «открытку» — прямоугольную область.
3. **Кликни по стикеру** на открытке — появится панель управления:
   - **Размер** — ползунок от 0.5× до 3×.
   - **Поворот** — ползунок от 0° до 360°.
   - **Удалить элемент** — красная кнопка.
4. **Текст:**
   - Введи текст в поле «Текст на открытке».
   - Появится превью-плашка.
   - Перетащи её на открытку или нажми **«Добавить»**.
   - Для текста работают те же настройки размера и поворота.
5. **Двойной клик** по стикеру — быстрое удаление.
6. **«Очистить»** — убрать все элементы с открытки.

Всё сохраняется автоматически в браузере. После оформления заказа открытка очищается и сохраняется в чеке (бейдж **«с открыткой»**).

### Оформление заказа

**Страница:** `/checkout.html` (кнопка **«Оформить заказ»** в корзине)

**Что на странице:**

1. **Состав заказа** — все позиции из корзины с фото, названием, вариантом (размер + топпинги), количеством и суммой по строке.
2. **Способ оплаты** — две кнопки:
   - **Онлайн картой** — оплата сразу.
   - **На месте** — оплата при получении в кофейне.
   
   Активная опция подсвечена зелёным с ореолом.
3. **Итоговые цифры:** количество товаров и общая сумма.
4. **Кнопка «Оформить заказ»** — отправить заказ.
5. **«← Назад в корзину»** — если нужно что-то поправить.

**После нажатия «Оформить заказ»:**
- Заказ создаётся на сервере.
- Корзина очищается.
- Открытка очищается.
- Редирект на страницу чека.

### Чек

**Страница:** `/receipt.html?id=N`

Красивый печатный чек, доступный сразу после оформления и позже из «Мои заказы».

**Что содержит:**
- **Шапка:** название кофейни, адрес, номер заказа, дата.
- **Бейджи:** статус заказа, способ оплаты, «с открыткой» (если ставил стикеры).
- **Таблица позиций:** название, вариант (размер, топпинги), количество × цена, сумма.
- **Итого** — крупная цифра.
- **Клиент:** имя и email.
- **Кнопки:** «← Мои заказы» и **🖨 Распечатать**.

**Печать:** при нажатии «Распечатать» браузер откроет диалог печати и **скроет** шапку сайта, футер и кнопки — распечатывается только сам чек.

### Мои заказы

**Страница:** `/profile.html` (кнопка с твоим именем в шапке или ссылка **«Мои заказы»** в навигации)

Доступна только авторизованным пользователям.

**Что на странице:**
- Список всех твоих заказов, новые сверху.
- Каждый заказ — карточка:
  - **Номер и дата**.
  - **Статус** — бейдж «Новый», «Оплачен», «Выполнен», «Отменён».
  - **Состав** — первые 3 позиции (или «… и ещё N»).
  - **Сумма.**

**Кнопки у заказа:**

| Статус | Доступно |
|---|---|
| **Новый** | — |
| **Оплачен** | **«Чек»**, **«Повторить»** |
| **Выполнен** | **«Чек»**, **«Повторить»** |
| **Отменён** | — |

**«Повторить»:**
- Все позиции заказа добавляются обратно в корзину с **теми же размерами и топпингами**.
- Товары подтягиваются из **актуального** каталога. Если товар удалён — пропускается.
- После добавления — редирект в корзину.
- Показывается тост: «Добавлено в корзину: N» (и «пропущено: M», если часть товаров недоступна).

**«Чек»** — переход на `/receipt.html?id=N` с полным чеком.

**Если заказов нет:** сообщение «У вас пока нет заказов» и кнопка в каталог.

## 🔧 Для администратора

### Вход в админку

**Через обычную форму входа:** `/login.html`

1. Email: `admin@coffee.ru`
2. Пароль: `admin123`
3. После входа — автоматический редирект на `/admin/dashboard.html`.

В шапке вместо имени появится **«Админка»** и кнопка **«Выйти»**.

**Прямой вход:** [http://localhost:3000/admin/dashboard.html](http://localhost:3000/admin/dashboard.html) — если уже залогинен как админ.

**Левое меню админки:**
- 📊 Статистика
- ☕ Товары
- 🍯 Топпинги
- 📝 Контент (блог)
- 🧾 Заказы
- ← На сайт

### Статистика

**Страница:** `/admin/dashboard.html`

**KPI-карточки (за последние 30 дней):**
- **Выручка** — сумма всех не-отменённых заказов.
- **Заказов** — количество.
- **Средний чек** — выручка / заказы.
- **Новых клиентов** — регистрации за период.

**Графики:**
- **«Продажи по дням»** — столбцы за последние 7 дней. Пропущенные дни = 0.
- **«Топ товаров»** — горизонтальные полосы, 5 самых продаваемых за всё время.

**Таблица «Последние заказы»** — 5 свежих заказов: номер, клиент, сумма, статус, дата.

**Примечание:** отменённые заказы не учитываются ни в KPI, ни в графиках.

### Управление товарами

**Страница:** `/admin/products.html`

**Таблица товаров:**
- ID, фото, название, категория, цена, размеры, сезонность, действия.
- Кнопки **✎** (редактировать) и **🗑** (удалить).

**Создание товара:** кнопка **«+ Добавить товар»** → модальное окно.

**Поля формы:**

1. **Название** — обязательное.
2. **Категория** — Кофе / Чай / Десерт.
3. **Сезонный** — чекбокс. Включает бейдж «Сезон» и приоритет в каталоге.
4. **Изображение:**
   - **Перетащи** файл в область — или **кликни** и выбери через проводник.
   - Форматы: JPEG, PNG, WebP, GIF. Максимум 5 МБ.
   - После загрузки — превью с кнопкой **✕** для удаления.
5. **Размеры (только для Кофе / Чая):**
   - Чекбоксы **S / M / L**.
   - У каждого — поле цены.
   - Отметь нужные размеры и впиши цену для каждого.
   - **Цена товара автоматически = минимальная из отмеченных.**
6. **Цена (только для Десертов):**
   - Одно поле цены.
7. **Описание** — необязательно.

**При смене категории:**
- Кофе/Чай → показываются размеры, скрывается поле «Цена».
- Десерт → скрываются размеры, показывается поле «Цена».

**Сохранение:** кнопка **«Сохранить»** внизу модалки. После сохранения — тост «Товар сохранён», список обновится.

**Удаление:** **🗑** → подтверждение → товар удалён. Старые заказы с этим товаром не ломаются.

### Управление топпингами

**Страница:** `/admin/toppings.html`

Сиропы и топпинги — добавки к напиткам. Управляются отдельно от товаров.

**Таблица:**
- ID, название, тип, цена, статус («активен» / «скрыт»), сезонность, действия.

**Создание:** кнопка **«+ Добавить топпинг»** → модальное окно.

**Поля формы:**

1. **Название** — обязательное.
2. **Тип** — Сироп / Топпинг.
3. **Цена** — неотрицательное число.
4. **Активен** — чекбокс (по умолчанию включён):
   - **Включён** → виден пользователям в каталоге и на странице товара.
   - **Выключен** → скрыт у пользователей, но остаётся в админке.
5. **Сезонный** — чекбокс:
   - При включении появляется поле **«Действует до»** (дата).
   - После этой даты топпинг **автоматически скрывается** у пользователей.
   - Сезонные топпинги помечаются бейджем «сезон» на странице товара.

**Редактирование:** **✎** — та же форма, поля предзаполнены.

**Удаление:** **🗑** → подтверждение → удалено. Старые заказы не ломаются (снимки сохранены).

**Совет:** если нужно временно убрать топпинг — не удаляй, а сними «Активен». Это можно откатить в один клик.

### Управление блогом

**Страница:** `/admin/content.html`

**Таблица:** ID, заголовок, дата, автор, действия.

**Создание:** **«+ Новая статья»** → модальное окно.

**Поля формы:**
1. **Заголовок** — обязательное.
2. **Краткое описание** — до 300 символов, отображается в карточке блога.
3. **Обложка** — URL изображения (например, `/uploads/post-1.jpg` после загрузки через API или любой внешний URL).
4. **Текст статьи** — основной контент.
   - Абзацы разделяются **пустой строкой** (два `\n`).
   - Внутри абзаца одиночный `\n` = перенос строки.

**Автор** подставляется автоматически — текущий админ.

**Редактирование:** **✎**, **удаление:** **🗑**.

Статьи сразу видны на `/blog.html` (список) и `/blog-post.html?id=N` (страница).

---

### Управление заказами

**Страница:** `/admin/orders.html`

**Таблица:** номер, клиент, сумма, статус, дата, действия.

**Фильтр по статусу** сверху: Все / Новые / Оплачены / Выполнены / Отменены.

**Смена статуса:** селект в каждой строке. Работает сразу, без перезагрузки.
- **Новый** (`new`) — заказ поступил.
- **Оплачен** (`paid`) — оплата получена. Автоматически ставится дата оплаты.
- **Выполнен** (`done`) — заказ выдан клиенту.
- **Отменён** (`cancelled`) — не учитывается в статистике.

**Чек:** кнопка **🧾** — открывает чек заказа в новой вкладке для печати или проверки.

**Статусы и действия у пользователя:**
- Пользователь видит кнопку **«Повторить»** и **«Чек»** только у оплаченных и выполненных заказов.
- У новых и отменённых — только просмотр состава.

## ❓ Частые вопросы

### Я не могу войти в админку

- Проверь, что вошёл под `admin@coffee.ru / admin123`.
- Если ты уже залогинен как обычный пользователь — сначала выйди, потом войди как админ.
- Если под админом кнопка «Войти» не превращается в «Админка» — очисти `localStorage` в DevTools (F12 → Application → Local Storage → Clear) и залогинься заново.

### Не вижу сезонные товары

- В каталоге сезонные идут **первыми** — прокрути вверх.
- Или поставь чекбокс **«Только сезонные»** в тулбаре над каталогом.
- Если в админке сезонных нет вообще — создай товар и отметь галочку «Сезонный».

### Топпинг пропал со страницы товара

- Если он **отключён** (`is_active = false`) — пользователям не виден.
- Если он **сезонный** и дата окончания прошла — автоматически скрывается.
- Проверь в админке: `/admin/toppings.html` → найди топпинг → статус / сезон.

### Заказ не появился в «Мои заказы»

- Заказ, оформленный **гостем** (без входа), не привязывается к аккаунту. Он есть в базе, но в «Моих заказах» его не будет.
- Чтобы был — войди перед оформлением.

### Не работает загрузка фото

- Форматы: **JPEG, PNG, WebP, GIF**. Не PDF, не HEIC.
- Размер: **до 5 МБ**.
- Если файл больше — сожми его или выбери другой.
- Проверь, что ты залогинен как админ — загрузка требует токена.

### «Оформить заказ» не работает

- Проверь, что в корзине есть товары (пустую корзину оформить нельзя).
- Проверь, что сервер запущен (`npm run dev`).
- Открой DevTools → Console → Network: `POST /api/orders` должен вернуть `201`.
- Если `400` — посмотри в ответе `message` (например, «Товар #N недоступен» — он удалён из БД).

### После пересоздания БД пропали заказы и товары

- Это нормально — при `DROP DATABASE` всё стирается.
- `npm run seed` создаёт только пользователей. Товары и топпинги приходят из `schema.sql` при импорте.
- Если нужны старые заказы — делай `mysqldump` перед пересозданием.

### Кириллица отображается как `????`

- На Windows MySQL-клиент читает `schema.sql` в cp1251.
- Решение: пересоздать БД с флагом:
  ```bash
  mysql -u root -p --default-character-set=utf8mb4 < database/schema.sql
  ```
- Файл `schema.sql` должен быть сохранён в **UTF-8 без BOM**.

## 🆘 Если что-то сломалось

1. **Открой DevTools** (F12) → вкладка **Console** — есть ли красные ошибки?
2. **Вкладка Network** — какой запрос упал? Какой статус (`401`, `404`, `500`)?
3. **Терминал с сервером** — есть ли ошибки в логах?
4. **`npm run dev`** — перезапусти сервер.
5. **Ctrl + F5** — сбрось кэш браузера (часто спасает после правок CSS/JS).
6. **`localStorage`** — если странные данные в корзине или шапке: F12 → Application → Local Storage → Clear, потом залогинься заново.

Если ничего не помогает — проверь, что база данных на месте:
```bash
mysql -u root -p -e "USE coffee_shop; SHOW TABLES;"
```

Должно быть 6 таблиц: `users`, `products`, `toppings`, `orders`, `order_items`, `posts`.
