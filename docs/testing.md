# MyCoffeCup — Документация тестирования

**Цель:** проверить работоспособность функционала, устойчивость к некорректным
действиям пользователя и корректность работы API.

**Методика:** ручное функциональное тестирование по чек-листам, проверка
через браузер (OperaGX) и API-клиент (Postman / curl).

**Окружение:**
- Windows 11, Node.js 18+, MySQL 8
- Клиенты: OperaGX
- Разрешения экрана: 1920×1080, 375×667 (мобильный)

## 🐞 Найденные и устранённые дефекты

| ID | Дефект | Причина | Решение |
|---|---|---|---|
| BUG-01 | Кириллица в БД отображается как `????` | Импорт `schema.sql` через `mysql` в cp1251 | Импорт с `--default-character-set=utf8mb4`; `charset: 'utf8mb4'` в пуле; `SET NAMES utf8mb4` в начале SQL |
| BUG-02 | Товары появляются, хотя в БД пусто | `catalog.js` возвращал `MOCK_PRODUCTS` при пустом ответе API | Удалены все моки, API — единственный источник; `MOCK_*` = `[]` |
| BUG-03 | Запись в блоге не удаляется | `admin.js` использовал `mock_posts` при HTTP-404 | Моки убраны; при 404 строка убирается из UI |
| BUG-04 | Графики в админке растягиваются бесконечно и вешают страницу | Chart.js при `maintainAspectRatio: false` + `position: absolute` на canvas → бесконечный цикл | `.chart-wrap { height: 280px }`, `animation: false`, `resizeDelay: 200`, убран `position: absolute` |
| BUG-05 | `typeof Chart === 'undefined'` — графики не рисуются | CDN заблокирован | Локальная копия `chart.umd.min.js` в `/js/vendor/` |
| BUG-06 | После логина кнопка «Войти» остаётся белой | Стиль `.btn--secondary` переопределялся | Точечное правило `.header-actions [data-auth-link]` — зелёная, как primary |
| BUG-07 | Кнопка «В корзину» не превращается в счётчик сразу | `activeElement` = кнопка → перерисовка блокировалась | Проверка `activeElement.matches('[data-qty-input]')` + `forceRenderActions()` после `Cart.add()` |
| BUG-08 | Подвал «висит» выше нижней границы на коротких страницах | `body` не растягивал main | `body { display: flex; flex-direction: column }`, `main { flex: 1 }` |
| BUG-09 | Дубликат «Мои заказы» в навигации | Ссылка была в HTML и добавлялась ещё раз через `header.js` | Убрана из HTML, добавляется только динамически |
| BUG-10 | Разделительная линия в таблице админки «съезжала» | `.table-actions { display: flex }` на `td` ломал table-cell | Убран `display: flex`, кнопки inline-flex, `td` остался table-cell |

## ⚠️ Известные ограничения

- **Нет интеграции с реальной платёжной системой.** `payment_method` сохраняется, статус `paid` ставит админ вручную.
- **Нет системы миграций.** При изменении схемы БД пересоздаётся целиком; тестовые данные пересоздаются через `npm run seed`.
- **Файлы изображений не удаляются** при удалении товара — остаются в `client/public/uploads/`. Чистятся вручную.
- **Корзина на клиенте** — при смене схемы (например, добавлении поля в ключ) старые позиции в `localStorage` могут стать «призрачными». Решается очисткой `localStorage.cart`.
- **Тестирование ручное** — автотесты не написаны.
